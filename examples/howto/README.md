# HOW TO example files

Sample source files used by `docs/HOWTO.md`:

- `temperature.csv` — structured CSV (value,width,comment) for the `csv`
  reader: shows multi-byte values, endianness and comments.
- `status.raw` — a simple raw-text table.
- `row_A.txt` / `row_B.txt` — two members for the batch-table walkthrough.

The readers/writers used in the guide come from `examples/plugins/`
(not installed by default — the guide tells you how to install them).
